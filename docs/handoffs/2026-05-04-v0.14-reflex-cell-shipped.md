## Decisions locked in

- v0.2 spec is parallel to v0.1, not a replacement. HedonismPolicy + valence harness retained as deliberative comparison branch.
- Auto-reproduction is a substrate phase (model.step() phase 4.5), not a behavior. Voluntary REPRODUCE remains in the Action enum and `get_valid_actions` for HedonismPolicy backward compat.
- Unbounded mutation enforces only physical floors/ceilings; lineages may drift outside founder TraitConfig ranges. Default off preserves v0.7..v0.13 bit-identity.
- No archetype injection in v0.14 founder pipeline. `experiments/trait_archetypes.py` retained as a comparison tool but not invoked.
- GradientPolicy semantics: STAY when no positive net pull. Only strictly-positive ties tie-break via rng.
- Memory stripped from v0.14. Deferred to v0.15+ per [[docs/specs/v0.2_reflex_cell_spec.md]] §"Out of scope".
- `novelty_drive` semantic-debt cleanup deferred to a future refactor slice.

## Watch-outs

- v0.14 sweep artifacts under `runs/fear-hunger-v0.14*/` are gitignored (verify via `.gitignore`); the only durable record of results is in `docs/experiments/fear_hunger_v0.14.md`.
- `unbounded_mutation` defaulting to False is load-bearing for v0.7..v0.13 bit-identity. Any future TraitConfig change that flips that default would invalidate the determinism north star for prior experiments.
- `apply_auto_reproduction` emits `ReproductionRequested` events identically to voluntary REPRODUCE; the existing metrics aggregators count both pathways without distinguishing them. If a future experiment needs to distinguish, extend the event payload.
- Founders are recorded in `model.trait_fingerprints` at birth_tick=0; children at the queue tick. Lineage analysis must filter by parent_id presence to distinguish.
- `experiments/comparison_grid.py` writes per-run `trait_fingerprints.csv` by reading `model.trait_fingerprints` after the run. If a future experiment uses a different driver, the file will not appear; the speciation script handles missing CSVs by returning empty rows.
- v0.14a tight_gradient sweep produces 47 successful lineages but 0 surviving past first generation; the high count is "founders reproduce once early then die," not "lineage compounding." Speciation analysis should filter `offspring_count >= 2` for a fair view of compounding lineages — that filter is noted but not yet implemented.
