## Next concrete step

Cut a fresh branch from `main` at `aa9ad20`. Implement v0.12 = **action-aware directional read** as the smallest experiment. The change: when `predict-one-step` evaluates a candidate `MOVE_X`, the policy (or sensor) should return *only* the X-direction slot of `pleasure_tendency` / `pain_tendency` in `remembered_good_*` / `remembered_bad_*` — not all four directions summed. The cleanest seam is in [[src/hedonism_harness/policies/hedonism_policy.py]] (which already evaluates each candidate); pass the candidate Action through to a new helper that re-projects the predicted observation's memory fields. Alternative seam: pass the candidate Action into `observe(...)` and let `_read_memory_directional` dispatch with action context — but that touches the sensor interface. Reuse the v0.11 grid driver unchanged (`memory_type="directional"`); just sweep on both chambers again. Pre-register the v0.7b 6-criterion rule unchanged. If v0.12 STILL produces no behavioral change, pivot to (2) per-cell-kind categorical for v0.13. Discuss the approach with user before coding — there is a real architectural choice in WHERE the action-direction projection happens.

## Watch-outs

- **`memory_type` axis defaults to `"cell_exact"`** — easy to forget when writing v0.12 sweeps; remember to pass `memory_type="directional"` explicitly. See [[src/hedonism_harness/experiments/memory_grid.py]] `all_grid_cells(layout_name=, memory_type=)`.
- **Cell-exact memory's decision power comes from its position-dependent scan, not the EMA recurrence.** v0.11 proved this. Any new representation must be position-aware (or action-aware) to bite.
- **Determinism north star**: [[scripts/core_smoke_test.py]] + [[tests/test_simulation_determinism_mesa.py]]. Both pass at handoff. v0.7/v0.7b/v0.8 sweeps were verified bit-identical post-decay-wiring; v0.9/v0.10 will re-run bit-identical when `memory_type="cell_exact"`. Re-verify after any v0.12 core change.
- **`MemoryTelemetryCollector.observe_tick` reads `agent.memory.visits` for ValenceMemory and `agent.memory.pleasure_tendency` for DirectionalMemory.** A new memory type in v0.12+ must add a dispatch branch or the telemetry will crash mid-sweep (we hit this exact bug during v0.11 sweep run).
- **The valence harness routes `_remembered_good_total` into `novelty_pleasure = novelty_score * traits.novelty_drive`.** Memory's signal-to-noise vs other pleasure terms (eating, safety, anticipated_food) may be too weak even when position-coupled. Worth profiling in v0.12.
- **Branch protocol**: stale `claude/v0.10-memory-ladder-control` and `claude/v0.11-directional-memory` were pruned locally; remote refs persist (the local proxy forbids ref deletion via 403). They're harmless merged labels.
- Project ladder (post-v0.12): if action-aware fixes directional → measure lineage depth (v0.13) or extend tick budget. If it doesn't → categorical memory (v0.13) → re-evaluate whether HedonismPolicy structure is the bottleneck rather than representation.
