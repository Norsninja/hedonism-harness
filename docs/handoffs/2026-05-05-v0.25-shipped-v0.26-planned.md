## Watch-outs

- **Bit-identity preservation is load-bearing.** Adding `hazard_avoidance_weight` parameter must default to behavior identical to current code. Any prior arm tuple's sweep output must remain byte-identical. The v0.22 pattern (Arm field defaults to None; threading falls back to existing default when None) is the right template.
- **Population dynamics library is now in main** ([[src/hedonism_harness/experiments/population_dynamics.py]]). v0.26 results doc can use `aggregate_cell` directly without inlining.
- **GradientPolicy avoidance mechanics:** the avoidance currently keys directly off per-tile `hazard_damage`. The decoupling needs to introduce a separate weight that is multiplied with (or replaces) the damage-derived signal. Find the exact line in the policy before designing the seam.
- **food_ladder negative-control prediction for v0.26:** avoidance=0 should NOT meaningfully change food_ladder b>50 (food_ladder agents already cross hazards regardless of avoidance because the food zone is past the hazard wall — pre-food band routes them around it geometrically). If food_ladder shifts substantially under avoidance=0, the chamber-geometry-as-buffer reading needs further revision.
- **Anchors for v0.26:** avoidance=1.0 cells should reproduce v0.25 byte-identically across all (chamber, hazard, influx) cells in V0_25_ARMS. Halt condition.
